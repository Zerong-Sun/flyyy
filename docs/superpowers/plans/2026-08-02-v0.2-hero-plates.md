## 1. 背景与目标

`game/data/world.json` 现有 **500 座城市**，其中仅 **20 个 Demo 枢纽** 拥有真实头图
（`game/assets/cities/city_{city_id}_hero_720.webp`），其余 **480 城** 运行时回退到
`logo_mark` 占位（见 `IconFactory.gd:get_city_hero`）。

本任务按已批准的 `region_plates` 策略，为 480 城补齐**程序生成**头图：
- 每个区域 1 张**区域底板**（横向 16:9 旅行海报风格：天空渐变 + 剪影天际线 + 地面）。
- 每城从底板派生**色调变体**：以 `city_id` 为确定性种子，微调色相/明度/构图，使同区域
  城市间肉眼可辨。
- 输出到 `game/assets/cities/`，命名沿用 `city_{city_id}_hero_720.webp`。
- 更新 `game/assets/i18n/attribution_zh.txt`，明确标注为程序生成过渡资产（区域底板+色调）。

## 4. 生成器设计

### 4.1 画布与输出
- 尺寸 **1280×720**（REQ §3.1），WebP 有损 quality≈82，RGB（无 alpha）。
- 幂等：默认跳过已存在文件；`--force` 重生成；`--only-missing`（默认）。
- 确定性：所有随机均由 `seed(city_id)` 派生，重跑结果一致。

### 4.2 区域底板（约 12 张）
在 9 个既有区域基础上，把 `global` 128 城按地理归属展开为补充区域，共约 **12 个区域底板**：

| 区域 | 视觉基调（旅行海报） | 天/地/强调色示意 |
|------|---------------------|------------------|
| europe | 暮色尖塔 + 红瓦天际线 | 冷蓝→暖杏，赭石 |
| east_asia | 晨雾 + 楼阁剪影 | 玫瑰→青碧，黛青 |
| southeast_asia | 热带青绿 + 水畔吊脚 | 青碧→暖沙，椰褐 |
| south_asia | 晨昏 + 穹顶塔寺 | 藏红→靛蓝，金 |
| middle_east | 沙漠 + 圆顶尖塔 | 赭金→紫霞，焦土 |
| north_america | 冷钢 + 摩天群像 | 钢蓝→珊瑚，雾灰 |
| south_america | 层峦 + 海岸城市 | 翠绿→暖橙，陶红 |
| africa | 稀树草原 + 平顶建筑 | 金橙→绯红，橄榄 |
| oceania | 海岬 + 港口小城 | 海蓝→鼠尾草，礁青 |
| central_asia | 旷野 + 驿站圆顶 | 土灰→驼金，沙褐 |
| caribbean | 碧海 + 彩色殖民街 | 湖绿→鲑粉，白垩 |
| pacific_islands | 环礁 + 椰林 | 钴蓝→浅碧，浪白 |

- 每张底板 = 天空垂直渐变 + 低悬日/月圆盘 + 2–3 层剪影（远景山体/中景天际线/近景地面带）+ 顶部微弱噪点颗粒 + 底部 20% 区域做轻微压暗（配合安全区叠字）。
- 天际线剪影为**几何程序化**：矩形塔楼、尖顶、圆顶、吊脚等基本形，按区域参数生成，不涉及商标/建筑实照。

### 4.3 城市色调变体（确定性派生）
- 种子：`hashlib.sha256(city_id)` 前 4 字节 → `random.Random(seed)`。
- 变化量（保持区域内可辨、不过度离散）：
  - 天空渐变上下两色各做 ±10° 色相、±12% 亮度抖动；
  - 强调色/天际线色做 ±8° 色相偏移；
  - 天际线建筑高度/间距/剪影层数按种子抖动（每城构图不同）；
  - 圆盘位置 x/y 微移。
- 变化包络固定（seed 派生），保证同城重跑一致、异城不同。

### 4.4 国家→区域映射（脚本内常量，仅美术）
- 复用 `run_pipeline.py` 的 69 国 9 区域；
- 补 83 国映射，示例：`AF/GE/AM/AZ/TJ/TM/UZ/KG→central_asia`，
  `CU/JM/HT/BS/BB/BM/GD/AG→caribbean`，`GT/BZ/HN/NI/CR/SV→north_america(中美洲组)`，
  `BG/HR/RO/RS/SK/SI/UA→europe`，`KP→east_asia`，`KI/SB/VU/WS/TL/PG→pacific_islands`，
  `KZ→central_asia`，`DZ/TN/CI/CM/MW/MZ/ZW→africa`，`IR/IQ/YE/CY→middle_east` 等。
- 映射表写入脚本常量，供 trace 与审读。

## 5. 执行步骤

   - 常量：区域底板定义（配色、剪影参数）、扩展国家→区域映射、输出尺寸。

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 程序底板与既有 AI 插画风格落差大 | 颜色取自现有头图主色采样（琥珀/青碧/暖沙系），构图走旅行海报剪影，避免拟真 |
| 128 城 `global` 区域归属偏差 | 脚本内扩展映射 + `--dry-run` 列国家清单人工过目 |
| 1280×720 与既有 640×360 混存 | 新文件按 REQ 720p 输出，游戏端按封面拉伸，无功能影响；记录在审读文档 |
| 生成文件过多（480×~50KB） | WebP q82 + 纯色渐变高压缩，预计总量 <30MB；不入 `_sheets` 到 git |
