# iOS Expo M3 — T1 性能核对 / U1 决议记录 — 2026-08-02

## T1 · 中端机拖转 ≥30 FPS（核对，代码级）

核对对象：`ios/expo/src/components/Globe.js`（RN 世界地图拖转）。

| 项目 | 结论 |
|------|------|
| 地球贴图 | 2 张静态 `Image`（等宽条带平移），无逐帧重算纹理 |
| 城市 Pin | 20 座全部注册，但仅 `vis && opacity>0.05` 的可见侧渲染（约 ≤12），隐藏侧为空 `View` 占位 |
| 拖转 | `PanResponder` → `setRot`；惯性用 `requestAnimationFrame` 逐帧 `rot *= 0.9`，无 JS 死循环 |
| Reduce motion | `optReduce` 时惯性直接关闭（`optReduceRef` 短路），符合 §设置 |
| 标签 | 仅「当前城市 / 票终点 / 已访问且近缘」显示 IATA，避免 20 个常驻 Label |
| 重算成本 | 每帧 `projectPin × 20 + sampleArc(≤28 点)`，纯数值计算，无重资产 |

**结论**：渲染树很轻（约 20–30 个 View + 2 Image），在 React Native 上不存在明显瓶颈，
中端机拖转 ≥30 FPS 目标**代码级达标**。真机 Profiler 属 v1.0 GATE 发布前项，
当前里程碑以代码预算核对为准（无法在无头环境实测帧率）。
