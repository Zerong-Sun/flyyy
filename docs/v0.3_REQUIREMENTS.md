## 1. 目标

在 v0.2「全球可玩 + 图鉴感」之上，交付 **航空运营深度**：经停、MCT 感知联程、延误/取消模拟、联盟展示、头等舱、冷鲜行李与危险品提示——强化「真实航线约束」而不破坏轻度贸易节奏。

## 2. 范围

### 2.1 In Scope（本版）

| # | 能力 | MR |
|---|------|-----|
| D1 | 机场 MCT 表 + economy.mct | V3.1 |
| D2 | 航司联盟目录（通用联盟名，无商标 Logo） | V3.1 / V3.3 |
| D3 | 经停航班（单经停、不下机） | V3.1 / V3.2 |
| D4 | 联程 MCT 校验与过场转机提示 | V3.2 |
| D5 | 延误 / 取消模拟（可配置、可关闭） | V3.3 |
| D6 | 头等舱定价与行李额度 | V3.4 |
| D7 | 冷藏行李 + 冷链品质衰减 | V3.4 |
| D8 | 危险品/禁运提示（软提示，不硬阻断） | V3.4 |
| D9 | 成就补集（头等/经停/延误/联盟） | V3.3 |

### 2.2 Out of Scope → v1.0

- 授权完整时刻表、全年季节、Steam 云成就、多语言全文翻译
- 多中转（>1 hub）、共享代码联营细节、机型限制硬拦截
- 真实航司 Logo / 实时联网航班

## 4. 运行时行为摘要

| 系统 | 行为 |
|------|------|
| `FlightSearch.search_connections` | 使用边/机场 MCT；头等舱估价 |
| `TicketService` | 舱位 economy/business/first；冷藏档；联程 MCT 排班 |
| `FlightOps` | 种子化延误/取消；取消退 70%；联程段间转机提示 |
| `EconomySystem.current_quality` | 冷链商品按 protected/unprotected 倍率衰减 |
| `InventorySystem.buy` | 危险品/冷链软提示（不阻断） |
| `MainHUD` | 头等舱按钮、冷藏档、经停/联盟/MCT 文案 |
