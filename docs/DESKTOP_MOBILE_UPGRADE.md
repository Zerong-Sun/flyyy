# 桌面与手机端升级记录

维护范围：Godot 桌面客户端和 Expo 手机端。HTML 设计原型未修改；“桌面版”不代表已适配 PlayStation、Xbox 或 Switch。

## 存档与兼容

- Godot 存档版本 2：写入临时文件并校验，保留上一份有效 `.bak`，原子替换主文件。主文件损坏时回退；未知新版本保护不覆盖。
- Godot 在资金、库存和机票变化后延迟自动保存，失去焦点或关闭时保存。飞行过场保留起飞前检查点，抵达后保存完整结果。
- 手机存档版本 3：校验库存、商品 ID、数量、金额、城市和机票数据；保留上一份有效副本。写入串行执行，失败不会提示保存成功；进入后台触发保存。
- 旧档的钱、位置、库存与进度保留。旧版没有完整旅费记录，因此升级后开始新的收益统计期间；不伪造历史净利。旧手机机票没有实付金额的部分不补发退款。
- 手机读档时起飞倒计时已为零，也会继续进入登机流程。

## 经济与玩法

- 普通市场卖价在事件、季节和需求修正后仍不超过当地买价的 95%，堵住事件带来的即时同城套利。
- 商品毛利 = 销售收入 − 已售商品采购成本。累计已实现净利 = 累计商品毛利 − 交通净支出。机票、行李和货运在支付时记录一次，退款抵减费用，分批销售不会重复扣费。
- 手机退票返还已付金额的 70%，亏损计入收益；丢弃商品计入损失。
- 航线面板比较预计净收益、每公斤收益和含候机的耗时。空仓可获得资金与重量范围内的采购建议，首趟目标是覆盖采购及旅费。
- 当前推荐比较未来 24 小时内的经济舱标准行李直飞方案；货运、受限品和联程仍由原购票界面规划。估算不是未来成交价保证；桌面版估算考虑保质期及销售中的需求衰减。

## 内容与运行性能

- `tools/export_expo_data.py` 生成 JSON 快照和可被 Metro/Node 同时导入的 `ios/expo/src/worldContent.js`。
- 手机端实际读取共同的机场坐标与航线图，不再默认所有城市之间有直飞服务。时刻与票价仍是手机端模拟配置，不是真实时刻表。
- Godot 使用 500 个机场、2500 件商品；手机端保留 20 个枢纽和 51 件精选商品及旧 ID。平台差异记录于 `ios/config/mobile_balance.json`，尚未把两端经济引擎合并。
- 手机地球旋转状态留在组件内，拖动采用起点角度加累计位移，避免拖动放大以及每帧触发全局存档调度。
- 手机背景音乐按实际当地小时切换，避免 12 小时显示格式影响判断；异步切换会丢弃过期音轨请求。
- 测试加载百万级航班复用一次读取；文件名 ID 用 NFC 规范化，避免 macOS Unicode 差异引发误报。

## 验证命令

```sh
python -m pytest tests -q
python tools/test_godot.py
python tools/test_godot.py --render SmokeUI.gd
python tools/export_expo_data.py --check
cd ios/expo
npm test
CI=1 npx expo export --platform ios --output-dir /tmp/flyyy-ios-export
```

Godot 需要先打开项目完成资源导入；命令行可用 `Godot --headless --path game --editor --import --quit`。测试工具使用独立存档目录，日志出现脚本错误或超时即失败。`GODOT_BIN` 可指定可执行文件。UI 渲染测试截图输出到 `/tmp/flyyy-desktop-flights.png`。

双次 ETL 确定性测试已改为在独立临时工作区生成，避免干扰运行中的游戏与其他测试。

Expo 导出验证 JavaScript/Hermes 与资源打包，不等于安装包签名、App Store 审核或真机触摸性能验收。当前环境无可用 iOS Simulator；真机后台恢复、音频与触摸需后续设备验收。

## 本轮验证结果

- 手机逻辑测试 50 项通过；iOS Hermes 和资源导出通过。
- Python 数据与资源回归 160 项通过、3 项条件跳过；随后新增的运行时导出契约与数据管线专项 12 项通过，含双次 ETL 字节一致性检查。两组存在重叠，不能相加。
- Godot 12 组隔离冒烟测试通过，覆盖挑战、收集、联程、冷链、声望、资源、音频、需求、性能、主界面、保存与收益回归。保存测试另外启动新进程读取原文件。
- 桌面航线面板用实际 OpenGL 渲染截图检查；推荐窗口调整为未来 24 小时，避免推荐十几天后才起飞的最低价航班。

后续六维验证与补修结果见 [验证修复清单](VALIDATION_FIXES.md)。
