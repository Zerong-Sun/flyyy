# 万里行商 v0.6.0 · 商机与奇遇

- **限时商机**：24–72 游戏小时的交货窗口，地图显示倒计时，可以分批出售完成订单。
- **30 个途中事件**：每趟最多一次、两个短选项；可以锁价、承担行情风险、换取优惠或调整订单期限。
- **连续委托**：最多三段，后续奖励递增；每段结束都可以收手。
- **随机商人专长**：商品或品类销售额达标后出现候选能力，只装备一个，新选择替换旧能力；飞行次数还能解锁航空常客能力。
- **开局菜单修复**：修复文字初次排版把面板撑出屏幕、导致开局菜单呈现空白的问题。
- **更简洁的操作**：在“市场／航班 → 商机”查看订单与专长，保留原有分批出售操作，减少普通出售和抵达时的强制弹窗。

支持读取旧存档，新玩法进度随存档保存。桌面包含原有 Dark / Light 双外观。

## 下载

- Windows 10/11 x64：`WanliTrader-v0.6.0-windows-x64.zip`。解压后运行 `WanliTrader.exe`，保留同目录的 `.pck` 文件。
- macOS（Apple Silicon / Intel）：`WanliTrader-v0.6.0-macos-universal.zip`。解压后运行 `WanliTrader.app`。应用未做 Apple 开发者公证，首次打开可能需要在“系统设置 → 隐私与安全性”选择“仍要打开”。
- 使用 `WanliTrader-v0.6.0-SHA256SUMS.txt` 校验下载文件。

手机 Expo 源码同步接入新玩法。本次下载附件仅包含桌面客户端，没有新的 IPA / APK；手机仍通过 Expo Go 预览。
