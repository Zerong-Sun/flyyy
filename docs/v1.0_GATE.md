# 《环球航商》v1.0 商业版门槛清单

| 字段 | 内容 |
|------|------|
| 文档编号 | GATE-v1.0 |
| 关联 | [PRD_01.md](../PRD_01.md) §25 v1.0 |
| 状态 | 门槛定义（不排实现细节） |

本文档只定义 **进入商业版开发前必须满足的门槛与交付物**，不拆 MR。

## 1. 内容与数据

| 门槛 | 说明 |
|------|------|
| 授权历史航班时刻表 | 有可商用许可的数据源合同或等价授权证明 |
| 完整 2025 季节 | 至少覆盖一个完整夏/冬航季；ETL 可切换季节包 |
| 校准全球商品价格 | 价格锚点抽检报告 + 经济模型文档；禁止「稳赚」宣传 |
| 更高质量城市库 | L2 城 A/B 置信度占比达标（阈值待定，建议 A+B ≥70%） |

## 2. 平台与发行

| 门槛 | 说明 |
|------|------|
| 多语言 | UI + 城市正文至少 中/英；结构对齐 CAS §3.8 |
| Steam 成就 | 与游戏内成就墙映射；云同步策略文档 |
| 云存档 | 供应商选型 + 冲突合并策略 |
| 创意工坊 | 数据包接口：城市/商品/航班增量包 schema + 校验器 |

## 3. 质量门禁

| 门槛 | 说明 |
|------|------|
| 法律页 | 数据来源 / 重建声明 / 字体与音频 attribution 完整 |
| 性能 | 1080p 地球漫游 ≈60 FPS（正式贴图开启） |
| 无障碍 | 减少动态、字幕/字号、色盲友好标签 |
| 回归 | Demo §27 + v0.2 §7.3 + v0.3 验收清单全绿 |

## 4. 明确永不进入

- 真实购票 / 实时航班追踪 / 未授权航司 Logo
- 酒烟药武等禁售商品
- 完整驾驶舱模拟

## 5. 前置依赖

- 桌面 v0.3 航空运营深化已验收  
- 移动 M3（或明确放弃移动发行）决议已记录  
- CAS 美术/音频 D1 剩余项关闭
