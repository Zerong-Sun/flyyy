## 需求核对

需要实际交付：保存可靠性、普通交易防即时同城套利、正确的毛利/净利核算、有效起飞与读档恢复、共享机场/航线契约、手机地球操作和保存性能、可负担的新手路线与清楚的收益解释。商品规模与模拟航班时刻仍按平台配置，不声称两端共享完整经济引擎。

执行命令：

```sh
python -m pytest tests -q
python tools/test_godot.py
python tools/test_godot.py --render SmokeUI.gd
cd ios/expo
npm test
CI=1 npx expo export --platform ios --output-dir /tmp/flyyy-review-ios-final
```

本轮实际使用 Godot 4.7.1、Expo SDK 54；Python 使用已有测试虚拟环境。桌面截图位于 `/tmp/flyyy-desktop-flights.png`，日志位于 `/tmp/flyyy-review-*.log`（本机临时验证产物，不随代码提交）。

仍有平台验收边界：iOS Hermes 导出不是 iOS 真机验收；当前机器没有可用 iOS Simulator，因此不能声称已验证真机触摸、音频焦点或系统杀进程行为。桌面运行已验证 macOS，Windows/Linux 未在本机执行。本轮不新增平台能力或声称性能指标。
