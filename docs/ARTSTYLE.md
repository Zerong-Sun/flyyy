# ARTSTYLE.md — 万里行商 Wanli Trader 美术风格契约 (v1.0)

Status: RATIFIED 2026-08-14 (GDLC Playtest #4, art-craft-review cycle).
This document is the single source of truth for the art surface. Any deviation
requires a contract revision, not a silent asset swap.

## 1. Visual identity

Travel-poster realism: muted natural tones, soft sun-disc skies, rectilinear
skyline silhouettes, grain. No photoreal textures, no logos/trademarks, no
political markings (globe coastlines only). Chinese-first typography.

## 2. Color tokens (canonical: game/themes/DemoColors.gd)

BG_DEEP #0B1C2C · BG_PANEL #122A3D @88% · OCEAN #1A4A6E · LAND #3D6B4F ·
ICE #D9E6F0 · TEXT_PRIMARY #F2F6FA · TEXT_SECONDARY #A8B8C8 · ACCENT_AMBER
#E89A3C · ACCENT_TEAL #3CB8A4 · WARN_RED #E57E7E · PROFIT_GREEN #73D98C ·
ECONOMY #7EB6D9 · BUSINESS #C9A45C · BORDER #2A455A.

- No raw `Color()` literals in UI code (grep-enforced; PROFIT_GREEN replaced
  the inline profit-green).
- Contrast floor: text ≥ 4.5:1 (WCAG AA) on every surface it renders on —
  tokens, scrim strips, and panel composites (ratchet:
  tests/game/test_visual_contract.py).

## 3. Typography

UI: Noto Sans SC Regular (OFL) · numeric/mono: JetBrains Mono Regular (OFL) ·
base 15px, accessibility scales 1.0/1.25/1.5 via ThemeFactory.

## 4. City hero plates

- All cities: `game/assets/cities/city_{city_id}_hero_720.webp`, WebP RGB.
- 480 procedural: exactly 1280×720, quality 82 method 6, generated by
  tools/art-gen-kit/gen_city_plates.py (deterministic, sha256-seeded —
  byte-identical re-runs).
- 20 hub plates: AI-authored. Current size 640×360 is a documented EXCEPTION
  (re-crop to 1280×720 or re-classify before v1.0 — GDLC Playtest #4 F1).
- Region tint bands: 13 regions + global, specs in gen_city_plates.py REGIONS.
- Safe-zone: bottom 10% luminance darker than top 10% (name legibility).
- No orphan plates: |city_*.webp| == |world.json cities| (ratchet-enforced).

## 5. Icons

- Source 2× display size: UI icons 256px source / `_32` display; product +
  achievement 128px source / `_64` display. Suffix = display size (enforced).
- Fallback: glyph-on-color tiles (IconFactory._DEFS) — never the logo_mark.
- Achievements: 36 total; 15 dedicated art, 21 alias fallbacks (documented).
- PRD-banned category icons (tobacco/wine/beer/etc.) never ship (ratchet).

## 6. Globe & flight transition

- Albedo: tools/generate_earth_albedo.py, 2k/4k/placeholder, palette from §2
  (attribution: Natural Earth 1:50m coastlines, public domain).
- The globe renders on a themed WorldEnvironment (BG_DEEP sky + ambient) —
  never the engine default clear color (ratchet).
- Transition frames: 6 frames, uniform 1280×720 (ratchet).

## 7. Audio pairing (canonical: AUDIO_MANIFEST.csv)

Every ogg in the manifest with id/license/author/loop/bus. CC0 items carry
source URLs. BGM family: bgm_globe_day with market/menu/night variants.
